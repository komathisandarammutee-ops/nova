# Nova Experientia Mobile UI/UX Prototype

A safe static prototype based on the current Nova Experientia homepage.

## Mobile improvements
- Mobile-first responsive layout
- No hard-coded negative desktop offsets
- Fluid widths and responsive typography
- 44–48px touch targets
- 2-column mobile category/product grids
- Tablet and desktop breakpoints
- Responsive hero, A Motion section and footer
- Horizontal-scroll partner chips instead of overflowing text

## Test widths
320, 360, 390, 412, 430, 768, 1024 and 1440 px.

## Publish with GitHub Pages
1. Upload all files/folders to the root of your `nova` repository.
2. GitHub → repository **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select `main` and `/ (root)`.
5. Save and wait for the preview URL.

This prototype does not modify the live WordPress site.
